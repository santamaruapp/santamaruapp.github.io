Comment Reply Helper

運営者(santamaru)が自分の YouTube チャンネルに届いたコメントへ返信するための、個人用の内部ツールです。一般の利用者向けのサービスではありません。

プライバシーポリシー / Privacy Policy

このツールは、運営者自身のチャンネルのコメントを読み取り、運営者自身のチャンネル名義で返信するためだけに YouTube Data API を利用します。取得したデータを第三者に提供・販売することはありません。認証情報は運営者の端末内にのみ保存されます。

This tool is used only by its operator to read comments on the operator's own YouTube channels and reply as those channels via the YouTube Data API. No data is shared with or sold to third parties. Credentials are stored only on the operator's own computer.
